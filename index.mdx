open-attest collects signed security posture facts from your team's laptops and exposes them through an open API. It's built for startups preparing for SOC 2 who need endpoint evidence without the complexity or cost of a full MDM platform.

## How it works

open-attest has three components that work together:

<Steps>
  <Step title="Deploy the server">
    Deploy the reference server to Cloudflare Workers with a single command. It stores signed attestations in a D1 SQLite database — no infrastructure to manage, free tier covers ~50 devices.
  </Step>
  <Step title="Enroll your team">
    Share an enrollment link with your team. They install the agent binary and run `open-attest enroll`. The agent generates an Ed25519 keypair, registers with the server, and installs a background daemon.
  </Step>
  <Step title="Collect compliance evidence">
    The agent runs 13 posture checks every hour — disk encryption, firewall, screen lock, EDR presence, and more — signs each attestation, and submits it to the server. The admin UI shows compliance status across all devices.
  </Step>
</Steps>

## Key features

<CardGroup cols={2}>
  <Card title="Signed attestations" icon="signature">
    Every attestation is signed with Ed25519. The server verifies origin authenticity and record integrity — auditor-friendly tamper-evident records.
  </Card>
  <Card title="Cross-platform" icon="laptop">
    Native support for macOS, Windows, and Linux. Platform-specific checks use the right system APIs on each OS.
  </Card>
  <Card title="Zero infrastructure" icon="cloud">
    Runs on Cloudflare Workers + D1. No servers, no databases to provision, no Docker. The free tier handles ~50 devices.
  </Card>
  <Card title="Drift detection" icon="bell">
    The daemon monitors for posture changes between scheduled reports and submits an immediate attestation when a check value changes.
  </Card>
  <Card title="Admin UI included" icon="chart-bar">
    A React dashboard lets you view device compliance status, manage enrollment tokens, and rotate API credentials — no extra tooling needed.
  </Card>
  <Card title="Open source" icon="github">
    Every check, every byte sent to the server is visible. Audit the code, fork it, or extend it for your own compliance requirements.
  </Card>
</CardGroup>

## Posture checks

open-attest collects 13 security posture facts per device:

| Check | macOS | Windows | Linux |
|-------|-------|---------|-------|
| Disk encryption | FileVault | BitLocker | LUKS / dm-crypt |
| Firewall | Application Firewall | Windows Firewall | ufw / iptables / firewalld |
| Screen lock timeout | Screensaver idle time | Registry / powercfg | gsettings / KDE / XFCE |
| Screen lock password | sysadminctl | Registry | gsettings / KDE / XFCE |
| Login password | dscl authonly | net user | /etc/shadow |
| Password policy | pwpolicy | ADSI / net accounts | PAM / pwquality / login.defs |
| OS version | sw_vers | .NET Environment | /etc/os-release |
| EDR/AV presence | XProtect + process scan | SecurityCenter2 + Defender | Process scan + AppArmor/SELinux |
| Local admin | dscl | net localgroup | /etc/group (sudo/wheel) |
| MDM enrollment | profiles | dsregcmd | N/A |

<Note>
  open-attest gives you the raw posture data. [Screenata](https://screenata.com) turns it into audit-ready compliance evidence with control mapping, policy evaluation, and auditor-export reports.
</Note>
