---
title: "Get attestation"
description: "Retrieve a single attestation record including the signed payload and signature."
---

Returns a full attestation record as stored by the server. The `payload` field contains the original JSON that the agent signed, and the `signature` field contains the Ed25519 signature over those exact bytes.

---

## Get an attestation

<br />

**GET** `/v1/attestations/:id`

### Authentication

Requires an admin API key in the `Authorization` header:

```
Authorization: Bearer <API_KEY>
```

See [API keys](/api/admin/api-keys) for how to create an API key.

### Path parameters

<ParamField path="id" type="string" required>
  The `attestation_id` (UUID) to retrieve. This is the `attestation_id` generated by the agent and included in the submitted payload.
</ParamField>

### Response

<ResponseField name="attestation_id" type="string">
  UUID identifying this attestation, as submitted by the agent.
</ResponseField>

<ResponseField name="agent_id" type="string">
  The agent that submitted this attestation.
</ResponseField>

<ResponseField name="device_id" type="string">
  The device associated with this attestation.
</ResponseField>

<ResponseField name="schema_version" type="string">
  Payload schema version (e.g. `"1.0"`).
</ResponseField>

<ResponseField name="collected_at" type="string">
  ISO 8601 timestamp from the agent indicating when the checks were collected.
</ResponseField>

<ResponseField name="signature" type="string">
  Base64-encoded Ed25519 signature over the raw `payload` bytes, as submitted in the `X-Attestation-Signature` header.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the server stored this attestation.
</ResponseField>

<ResponseField name="payload" type="object">
  The full attestation payload as submitted by the agent. Contains `schema_version`, `attestation_id`, `collected_at`, `agent`, `device`, `user`, and `checks`. See the [attestation endpoint](/api/agents/attest) for the payload schema.
</ResponseField>

### Example

```bash
curl "https://your-worker.workers.dev/v1/attestations/7c9e6679-7425-40de-944b-e07fc1f90ae7" \
  -H "Authorization: Bearer $API_KEY"
```

### Error codes

| Code | Meaning |
|------|---------|
| `FORBIDDEN` | The API key is invalid or not authorized. |
| `NOT_FOUND` | No attestation exists with the given `attestation_id`. |
