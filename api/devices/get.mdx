---
title: "Get device"
description: "Retrieve a single device and its latest posture check values."
---

Returns a device record along with the most recent value for every posture check the device has ever reported. Check values are stored as a per-device map keyed by check name; only the latest observed value for each key is retained.

---

## Get a device

<br />

**GET** `/v1/devices/:id`

### Authentication

Requires an admin API key in the `Authorization` header:

```
Authorization: Bearer <API_KEY>
```

See [API keys](/api/admin/api-keys) for how to create an API key.

### Path parameters

<ParamField path="id" type="string" required>
  The `device_id` of the device to retrieve (e.g. `dev_12345678-1234-1234-1234-123456789abc`).
</ParamField>

### Response

<ResponseField name="device" type="object">
  Device record.

  <Expandable title="properties">
    <ResponseField name="agent_id" type="string">
      Unique agent identifier.
    </ResponseField>

    <ResponseField name="org_id" type="string">
      Organization this device belongs to.
    </ResponseField>

    <ResponseField name="public_key" type="string">
      Base64-encoded Ed25519 public key currently registered for this agent.
    </ResponseField>

    <ResponseField name="key_id" type="string">
      Identifier for the current registered public key (e.g. `key_<uuid>`).
    </ResponseField>

    <ResponseField name="hostname" type="string">
      Device hostname.
    </ResponseField>

    <ResponseField name="platform" type="string">
      Operating system: `macos`, `windows`, or `linux`.
    </ResponseField>

    <ResponseField name="platform_version" type="string">
      OS version string.
    </ResponseField>

    <ResponseField name="device_id" type="string">
      Stable device identifier.
    </ResponseField>

    <ResponseField name="status" type="string">
      Current agent status: `active` or `revoked`.
    </ResponseField>

    <ResponseField name="enrolled_at" type="string">
      ISO 8601 timestamp of initial enrollment.
    </ResponseField>

    <ResponseField name="last_seen_at" type="string | null">
      ISO 8601 timestamp of the most recent heartbeat or attestation.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="checks" type="object[]">
  Latest posture check results for this device. One entry per unique check key.

  <Expandable title="properties">
    <ResponseField name="device_id" type="string">
      Device identifier this check belongs to.
    </ResponseField>

    <ResponseField name="check_key" type="string">
      Check identifier (e.g. `"disk_encryption.enabled"`, `"os.version"`).
    </ResponseField>

    <ResponseField name="check_value" type="object">
      Tagged union with the latest check result. Contains `type` and `value` fields. See the [attestation endpoint](/api/agents/attest) for the full value format.
    </ResponseField>

    <ResponseField name="observed_at" type="string">
      ISO 8601 timestamp from the attestation when this check value was last observed.
    </ResponseField>

    <ResponseField name="source" type="string | null">
      The system tool or API that collected this check (e.g. `"fdesetup"`).
    </ResponseField>
  </Expandable>
</ResponseField>

### Example

```bash
curl "https://your-worker.workers.dev/v1/devices/dev_12345678-1234-1234-1234-123456789abc" \
  -H "Authorization: Bearer $API_KEY"
```

### Error codes

| Code | Meaning |
|------|---------|
| `FORBIDDEN` | The API key is invalid or not authorized. |
| `NOT_FOUND` | No device exists with the given `device_id`. |
